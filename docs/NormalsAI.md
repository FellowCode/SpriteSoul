Обнови проект **Sprite Soul**, добавив поддержку специализированной AI-модели для оценки Surface Normals.

Основная спецификация проекта остаётся действующей. Не переписывай существующую архитектуру и не делай большой рефакторинг, если он не требуется.

# Цель

Сейчас основной pipeline:

`Sprite → Depth AI → Final Depth → Normal from Depth`

Нужно добавить второй источник информации о геометрии:

`Sprite → Normal AI`

AI Normal нужен прежде всего как дополнительная геометрическая подсказка и альтернативный режим сравнения.

Не удаляй существующий детерминированный `Normal from Depth`.

# Модель

В качестве первого специализированного Normal backend используй **DSINE**.

Перед интеграцией проверь актуальную официальную реализацию и API DSINE.

Не копируй всю кодовую базу DSINE внутрь проекта, если модель можно подключить значительно проще.

Учитывай ограничение:

`RTX 3060 Laptop / 6 GB VRAM`

Используй FP16, если модель корректно его поддерживает.

Модель должна загружаться только при необходимости и освобождать VRAM, когда больше не нужна.

Если полный размер изображения не помещается в VRAM, используй resize/crop/tile подход без изменения координат финального изображения.

# Важная особенность Sprite Soul

Исходные изображения — преимущественно игровые 2D/2.5D спрайты:

- изометрические здания;
- деревья;
- техника;
- объекты;
- sprite atlases.

Это НЕ обычные фотографии.

Часто используется ортографическая или близкая к ортографической изометрическая проекция.

DSINE рассчитан прежде всего на изображения перспективной камеры, поэтому его результат нельзя автоматически считать физически правильным.

Если DSINE требует camera intrinsics/FOV, используй разумный configurable default, но не усложняй проект системой calibration.

Добавь настройку FOV только если она действительно необходима API модели.

# Pixel-perfect

AI не имеет права изменять:

- width;
- height;
- положение объекта;
- silhouette;
- alpha.

Normal AI должна быть приведена точно к координатам исходного изображения.

Финальная alpha всегда берётся из исходного PNG.

Для atlas результат должен возвращаться точно в исходные координаты.

# Режимы Normal

Добавь в интерфейс:

`Normal Source`

с режимами:

1. `Depth`
2. `AI`
3. `Hybrid`

## Depth

Существующий режим.

`Final Depth → gradient → Normal`

Он остаётся основным и полностью детерминированным.

## AI

Показывает результат DSINE после:

- преобразования координат;
- нормализации;
- применения исходной alpha;
- приведения к выбранной convention.

Поддерживаются:

`OpenGL +Y`
`DirectX -Y`

Не определяй знак Y визуально. Проверь преобразование координат DSINE по документации/коду модели.

## Hybrid

Не делай сложную систему fusion.

Для первой реализации достаточно контролируемого смешивания направлений:

`N = normalize((1-w) * N_depth + w * N_ai)`

где:

`w = AI Influence`

диапазон:

`0.0 ... 1.0`

Default:

`0.35`

При:

`w = 0`

результат должен точно соответствовать `Depth Normal`.

При:

`w = 1`

результат должен соответствовать нормализованной `AI Normal`.

Смешивать нужно float XYZ vectors, а НЕ RGB-пиксели закодированной normal map.

После смешивания обязательно нормализовать vector.

# UI

Не перестраивай интерфейс.

Добавь к существующим настройкам Normal:

`Normal Source: Depth / AI / Hybrid`

`AI Influence: 0.00 – 1.00`

Lighting Preview должен использовать выбранную Normal Source.

# Работа с Depth Editor

Ручное редактирование Depth НЕ изменяет AI Normal.

После изменения Depth:

- пересчитать `N_depth`;
- если выбран Hybrid — пересчитать Hybrid;
- DSINE повторно запускать не нужно.

Таким образом пользователь может использовать AI Normal как стабильную геометрическую подсказку и исправлять Depth вручную.

# Кэш

Результат DSINE необходимо кэшировать в памяти проекта.

Не запускай inference повторно при каждом изменении slider или brush.

Повторный DSINE inference нужен только если:

- изменился исходный RGB;
- пользователь явно нажал regenerate;
- изменились параметры DSINE, влияющие на inference.

# Архитектура

Сохрани существующую простую архитектуру.

Normal AI должен быть отдельным компонентом от Depth AI.

Например:

`depth/inference.py`
`normal_ai.py`
`normal.py`

где:

`normal_ai.py` — DSINE inference;

`normal.py` — normal-from-depth, conversion, normalization и Hybrid;

не создавай plugin framework, factory hierarchy или dependency injection.

Если существующая структура проекта отличается — адаптируй решение к ней, а не перестраивай проект ради этого примера.

Сначала качественно интегрируй DSINE.

# Проверки

Не создавай большой test suite.

Добавь только необходимые проверки:

1. `Hybrid(w=0) == Depth Normal`
2. `Hybrid(w=1) == AI Normal`
3. длина каждого normal vector после Hybrid ≈ 1
4. OpenGL/DirectX корректно меняет Y
5. output dimensions == source dimensions
6. output alpha == source alpha

# Производительность

Главный target:

**RTX 3060 Laptop 6 GB VRAM**

Не держи одновременно Depth AI и DSINE на GPU без необходимости.

Предпочтительный сценарий:

`load Depth model`
→ `Depth inference`
→ `offload/unload`

затем при необходимости:

`load DSINE`
→ `Normal inference`
→ `offload/unload`

Depth/Normal post-processing выполнять без тяжёлой GPU-модели.

Не усложняй VRAM manager. Достаточно явного lifecycle моделей.
