# Sprite Soul

## Ambient Occlusion

В меню **Генерировать → Карта AO** приложение использует Depth Anything V2, затем рассчитывает AO из итоговой карты глубины. Если Depth уже создана или открыта из `.ssoul`, повторный запуск нейромодели не требуется. В режиме просмотра **AO** доступны радиус и сила затемнения; изменение общих параметров обработки Depth сразу обновляет AO. Когда Depth доступна, **Lighting Preview** применяет AO к освещению и обновляется при изменении радиуса и силы. **Экспорт** сохраняет `_ao.png` с исходной прозрачностью вместе с Depth. По одному изображению получается приближённая AO только для видимого рельефа.

Локальный генератор Depth и Normal карт для PNG-спрайтов и атласов. При первой генерации приложение автоматически проверяет CUDA-сборку PyTorch и скачивает нужную модель: [Depth Anything V2 Small](https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf) или [DSINE](https://github.com/baegwangbin/DSINE) с [весами](https://huggingface.co/dylanebert/DSINE). Все модели, их веса и исходный код хранятся в игнорируемом Git каталоге `models/` внутри проекта. Для AI-генерации нужны видеокарта NVIDIA и драйвер; просмотр и обработка сохранённой Depth работают без CUDA.

## Установка на Windows

Для автоматической установки Python 3.11, создания `.venv`, установки зависимостей, CUDA-сборки PyTorch и AI-моделей запустите `setup_environment.bat` от имени обычного пользователя. Скрипт использует `winget`, если Python ещё не установлен. Финальный этап вызывает `python -m smg setup --models all --progress text` и загружает также IntrinsicAnything с checkpoint около 14,4 ГиБ.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe app.py
```

В интерфейсе кнопка **Подготовить AI** заранее установит CUDA-сборку PyTorch и загрузит модели Depth, DSINE и CLIPSeg. Нажимать её необязательно: каждая операция автоматически подготовит только нужную модель. Установка CUDA Toolkit вручную не требуется: используется готовая сборка PyTorch. Если драйвера NVIDIA нет или он слишком старый, приложение покажет ссылку на его установку.

Если нужной для выбранной операции модели нет, приложение сначала предложит скачать её в `models/`. После подтверждения загрузка и подготовка выполняются в фоне, а справа в строке состояния отображается индикатор прогресса. Отказ от загрузки отменяет только текущую генерацию. Для IntrinsicAnything диалог также предупреждает о размере checkpoint около 14,4 ГиБ.

## Командная строка

После установки доступна команда `sprite-soul` (на Windows в виртуальном окружении — `.\.venv\Scripts\sprite-soul.exe`). CLI работает без запуска PySide6:

```powershell
.\.venv\Scripts\sprite-soul.exe --help
.\.venv\Scripts\sprite-soul.exe generate --help
.\.venv\Scripts\sprite-soul.exe setup --help
.\.venv\Scripts\sprite-soul.exe generate sprite.png
.\.venv\Scripts\sprite-soul.exe generate sprite.png --maps all
.\.venv\Scripts\sprite-soul.exe generate sprite.png --maps normal
.\.venv\Scripts\sprite-soul.exe generate sprite.png --maps ao --ao-radius 32
.\.venv\Scripts\sprite-soul.exe generate sprite.png --maps ao --depth-map sprite_depth.png
.\.venv\Scripts\sprite-soul.exe generate sprite.png --progress json
.\.venv\Scripts\sprite-soul.exe setup
```

Можно также вызвать `python -m smg`. Режим `--progress json` выдаёт события JSON Lines в stdout, которые другая программа может читать во время установки и генерации. Подробные параметры, формат событий и пакетная обработка описаны в [руководстве CLI](docs/CLI.md).

Подать спрайт, сгенерировать все карты и сразу экспортировать PNG без сохранения проекта можно одной командой:

```powershell
.\.venv\Scripts\sprite-soul.exe generate sprite.png --maps all -o exported --no-save-project
```

В `exported/` появятся `sprite_depth.png`, `sprite_normal.png`, `sprite_albedo.png` и `sprite_ao.png`. Сохранение `.ssoul` по умолчанию выключено, поэтому `--no-save-project` можно опустить. Проект записывается только при явном `--save-project`.

Откройте PNG и выберите в верхнем меню **Генерировать** пункт **Карта глубины**, **Карта нормалей**, **Albedo** или **Все карты**. Normal создаётся только моделью DSINE: режимы Normal из Depth и Hybrid удалены. Нормали DSINE переводятся в OpenGL и кэшируются как float-векторы; DirectX получается инверсией Y при выводе. Перед показом и экспортом применяется постобработка полного разрешения: регулируемое alpha-aware сглаживание (`1.5` по умолчанию) сохраняет крупные наклоны DSINE, а настройка **Детали** (`0.35` по умолчанию) восстанавливает мелкий рельеф из высокочастотной яркости исходного спрайта. Контур и alpha не участвуют в вычислении рельефа. `Invert AI X` и `Invert AI Y` можно переключать без повторного inference. `DSINE FOV` задаёт предположение о камере (60° по умолчанию). Результат DSINE кэшируется в памяти до замены исходника, изменения FOV или явной регенерации. Колесо мыши меняет масштаб, перетаскивание двигает холст. Lighting Preview использует Albedo, когда она создана, иначе исходное изображение; перетаскивание двигает свет. **Экспорт** сохраняет только уже созданные карты: `_depth.png`, `_normal.png`, `_albedo.png`, `_ao.png` и `.ssoul` при наличии Depth. AI-кэш хранится только в текущем сеансе.

Ручное редактирование Depth кистями удалено. Для всей карты доступны Invert Depth, Range, Contrast и Smooth; перетаскивание в режиме Depth перемещает холст.

При генерации Normal приложение автоматически запускает локальную [CLIPSeg](https://huggingface.co/CIDAS/clipseg-rd64-refined) с запросом `tree canopy`. Маска расширяется до альфа-контура, отделяя листву от ствола. Если крона занимает строго больше 40% непрозрачных пикселей, спрайт считается деревом: выпуклая форма кроны смешивается с мелкими деталями нормали DSINE. Иначе остаётся обычная Normal DSINE. Переход от кроны к остальной нормали плавный. Автоматически найденная маска сохраняется в `.ssoul`; правило работает и в CLI. Уже сохранённая или вручную подтверждённая маска используется повторно без запуска CLIPSeg.

Кнопка **Определить крону** позволяет проверить и поправить результат вручную. Она показывает найденные кроны поверх изображения; ползунок **Порог** меняет чувствительность без повторного запуска модели. Нажмите **Готово**, затем **Экспорт**, чтобы сохранить маску внутри `.ssoul`; режим **Маска кроны** позволяет проверить её после повторного открытия проекта. **Отмена** сохраняет прежнюю маску. Если Normal уже готова, подтверждение маски сразу обновляет её предпросмотр.

## Guided Albedo

Кнопка **Генерировать Albedo** запускает локальную установку [IntrinsicAnything](https://github.com/zju3dv/IntrinsicAnything) из `models/IntrinsicAnything` в корне проекта. Этот каталог игнорируется Git. Если установка лежит в другом месте, задайте `SPRITE_SOUL_INTRINSIC_ROOT`. Нужны `inference.py`, `.venv-intrinsic` и `weights/albedo/checkpoints/last.ckpt` в этом каталоге. Кнопка **Экспорт** сохраняет `_albedo.png` даже без Depth. По умолчанию результаты помещаются в игнорируемую Git папку `generated/`; в `example_sprites/` хранятся только исходные тестовые PNG. В CLI используйте `--maps albedo` или `--maps all`; `--albedo-debug DIR` сохраняет вход 256×256, предсказание и карты коррекции.

Каждый спрайт подаётся модели один раз в 256×256 без тайлов. Из предсказания берётся сглаженное поле изменения яркости; оно применяется к RGB оригинального разрешения в linear RGB. Исходная alpha копируется без изменений. Для атласа близкие alpha-компоненты объединяются в один объект, а отдалённые обрабатываются отдельно.

Для запуска тестов: `.\.venv\Scripts\python.exe -m pip install -e ".[test]"`, затем `.\.venv\Scripts\python.exe -m pytest -q`.

## Эксперимент с albedo

Локально проверили [IntrinsicAnything](docs/IntrinsicAnything.md) на спрайтах дерева и колодца с RTX 3060 6 ГБ. В отчёте есть параметры прогонов, полученные PNG и оценка артефактов. Модель запускается на этой видеокарте, но в текущем виде теряет мелкие детали и не включена в генерацию Sprite Soul.
