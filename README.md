# Sprite Soul

Локальный редактор Depth и Normal карт для PNG-спрайтов и атласов. При первой генерации приложение автоматически проверяет CUDA-сборку PyTorch и скачивает нужную модель: [Depth Anything V2 Small](https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf) или [DSINE](https://github.com/baegwangbin/DSINE) с [весами](https://huggingface.co/dylanebert/DSINE). Все модели, их веса и исходный код хранятся в игнорируемом Git каталоге `models/` внутри проекта. Для AI-генерации нужны видеокарта NVIDIA и драйвер; редактирование сохранённого проекта работает без CUDA.

## Установка на Windows

Для автоматической установки Python 3.11, создания `.venv`, установки зависимостей, CUDA-сборки PyTorch и AI-моделей запустите `setup_environment.bat` от имени обычного пользователя. Скрипт использует `winget`, если Python ещё не установлен. Финальный этап вызывает `python -m smg setup --models all --progress text`, поэтому в окне видны понятные сообщения о проверке CUDA и загрузке каждой модели.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe app.py
```

В интерфейсе кнопка **Подготовить AI** заранее установит CUDA-сборку PyTorch и загрузит модели Depth, DSINE и SAM 2.1. Нажимать её необязательно: каждая операция автоматически подготовит только нужную модель. Установка CUDA Toolkit вручную не требуется: используется готовая сборка PyTorch. Если драйвера NVIDIA нет или он слишком старый, приложение покажет ссылку на его установку.

Если нужной для выбранной операции модели нет, приложение сначала предложит скачать её в `models/`. После подтверждения загрузка и подготовка выполняются в фоне, а справа в строке состояния отображается индикатор прогресса. Отказ от загрузки отменяет только текущую генерацию. Для IntrinsicAnything диалог также предупреждает о размере checkpoint около 14,4 ГиБ.

## Командная строка

После установки доступна команда `sprite-soul` (на Windows в виртуальном окружении — `.\.venv\Scripts\sprite-soul.exe`). CLI работает без запуска PySide6:

```powershell
.\.venv\Scripts\sprite-soul.exe --help
.\.venv\Scripts\sprite-soul.exe generate --help
.\.venv\Scripts\sprite-soul.exe setup --help
.\.venv\Scripts\sprite-soul.exe generate sprite.png
.\.venv\Scripts\sprite-soul.exe generate sprite.png --progress json
.\.venv\Scripts\sprite-soul.exe setup
```

Можно также вызвать `python -m smg`. Режим `--progress json` выдаёт события JSON Lines в stdout, которые другая программа может читать во время установки и генерации. Подробные параметры, формат событий и пакетная обработка описаны в [руководстве CLI](docs/CLI.md).

Откройте PNG и выберите в верхнем меню **Генерировать** пункт **Карта глубины**, **Карта нормалей**, **Albedo** или **Все карты**. Normal создаётся только моделью DSINE: режимы Normal из Depth и Hybrid удалены. Нормали DSINE переводятся в OpenGL и кэшируются как float-векторы; DirectX получается инверсией Y при выводе. Перед показом и экспортом применяется постобработка полного разрешения: регулируемое alpha-aware сглаживание (`1.5` по умолчанию) сохраняет крупные наклоны DSINE, а настройка **Детали** (`0.35` по умолчанию) восстанавливает мелкий рельеф из высокочастотной яркости исходного спрайта. Контур и alpha не участвуют в вычислении рельефа. `Invert AI X` и `Invert AI Y` можно переключать без повторного inference. `DSINE FOV` задаёт предположение о камере (60° по умолчанию). Результат DSINE кэшируется в памяти до замены исходника, изменения FOV или явной регенерации. Колесо мыши меняет масштаб, перетаскивание в режиме Pan двигает холст. Lighting Preview использует Albedo, когда она создана, иначе исходное изображение; перетаскивание двигает свет. **Экспорт** сохраняет только уже созданные карты: `_depth.png`, `_normal.png`, `_albedo.png` и `.ssoul` при наличии Depth. AI-кэш хранится только в текущем сеансе.

Кнопка **Выделить листву** загружает локальную **SAM 2.1 Base+** и переводит изображение в режим интерактивной сегментации. Выберите «Добавить» и кликните по кроне или кусту; переключитесь на «Исключить», чтобы убрать захваченные области. Полупрозрачное наложение показывает временную маску. Нажмите **Готово**, затем **Экспорт**, чтобы сохранить маску внутри `.ssoul`; режим просмотра **Foliage Mask** позволяет проверить её после повторного открытия проекта. Маска не изменяет карты Depth и Normal в текущей версии — она подготовлена для будущих правил нормалей.

## Guided Albedo

Кнопка **Генерировать Albedo** запускает локальную установку [IntrinsicAnything](https://github.com/zju3dv/IntrinsicAnything) из `models/IntrinsicAnything` в корне проекта. Этот каталог игнорируется Git. Если установка лежит в другом месте, задайте `SPRITE_SOUL_INTRINSIC_ROOT`. Нужны `inference.py`, `.venv-intrinsic` и `weights/albedo/checkpoints/last.ckpt` в этом каталоге. Кнопка **Экспорт** сохраняет `_albedo.png` даже без Depth. По умолчанию результаты помещаются в игнорируемую Git папку `generated/`; в `example_sprites/` хранятся только исходные тестовые PNG. В CLI используйте `--maps albedo` или `--maps all`; `--albedo-debug DIR` сохраняет вход 256×256, предсказание и карты коррекции.

Каждый спрайт подаётся модели один раз в 256×256 без тайлов. Из предсказания берётся сглаженное поле изменения яркости; оно применяется к RGB оригинального разрешения в linear RGB. Исходная alpha копируется без изменений. Для атласа близкие alpha-компоненты объединяются в один объект, а отдалённые обрабатываются отдельно.

Для запуска тестов: `.\.venv\Scripts\python.exe -m pip install -e ".[test]"`, затем `.\.venv\Scripts\python.exe -m pytest -q`.

## Эксперимент с albedo

Локально проверили [IntrinsicAnything](docs/IntrinsicAnything.md) на спрайтах дерева и колодца с RTX 3060 6 ГБ. В отчёте есть параметры прогонов, полученные PNG и оценка артефактов. Модель запускается на этой видеокарте, но в текущем виде теряет мелкие детали и не включена в генерацию Sprite Soul.
